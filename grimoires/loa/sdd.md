- `purpose-service`, `event-sourcing-service` — domain concerns
- `nowpayments-handler`, `x402-settlement` — payment surfaces
- `jwks-pg-service` — JWKS publication for JWT key rotation
- `legacy-backfill-service`, `arrakis-conviction-bridge` — migration/bridge services

### Apps (apps/)

- `gateway` — Rust Discord gateway publisher (Twilight + NATS)
- `worker` — TS queue consumer (dual-bus RabbitMQ + NATS)
- `ingestor` — TS event ingestion

### Theme (themes/sietch/)

Main consumer of `@arrakis/*` packages. `sietch-service` v6.0.0.

## 7. Security & Authn [GROUNDED]

- **JWT**: ES256 (ECDSA P-256), per ADR-002. JWKS published via `jwks-pg-service.ts` and `/.well-known/jwks.json` route.
- **Internal S2S**: `s2s-jwt-validator.ts`.
- **BYOK isolation**: `byok-proxy-handler.ts` egresses upstream with user-supplied keys; platform keys never exposed cross-tenant.
- **Vault, MFA, wallet verification, kill switch**: `packages/adapters/security/`.
- **Postgres RLS**: tenant_context_guard, multiple `rls_*` migrations.
- **Capability audit**: every gateway access emits `pool_access` / `byok_usage` / `ensemble_invocation` events.
- **Admin audit log**: `0018_admin_audit_log.sql` migration.
