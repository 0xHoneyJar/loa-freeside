# The verdict — BOTH, layered: constructs are the organs, a composition is the immune system

The regeneration loop (**doctor → aligner → teeth** + the operator-port + the silence render-rule) is a **sequence cut at gate seams** — which is exactly a **composition** shape (cf. `access-relay.yaml`: `sequence: [{construct, role, persona}]`). But each role needs a **construct** to play it. So:

| role (loop rung) | the organ (construct) | state today |
|---|---|---|
| **doctor** (sense any estate → a coherence tile) | **GECKO**, generalized | EXISTS (patrol/observe/diagnose/report) but scoped to the *construct* ecosystem + sense-only |
| **aligner** (make the governed path cheapest) | new skill / sibling organ | bespoke scripts only (recall mode-flip, beads align.mjs) |
| **teeth** (enforce, TIERED: invariant>gate>detector) | new skill / sibling organ | bespoke (hivemind gate, fail-loud hooks) |
| **operator-port** (paving/tilting sense) | a GECKO skill (the commons' 8th node) | the cheap script from this session |

**The primitive = a composition `immune-relay` (or `regenerate`)** that chains `doctor → aligner → teeth` parameterized by an *estate*, backed by **GECKO generalized from "construct-ecosystem health" → "any-estate health" (incl. the operator).** GECKO becomes the **immune system of the commons**, not just of constructs — the gardener persona made literal.

## Why this is the §9 floor-raise, not another script
- A NEW estate gets the immune system by **running the composition** — composed, not re-derived. The floor rises; the next one is free.
- It **reuses GECKO** (the organ furthest along) and the coherence-surface + operator-port from this session — *leaving things better than they started*, not building from zero.
- It **compounds**: the pattern is named once and composed N times. The doctrine stops being a pile of estate-doctors and becomes a network primitive.

## The smallest real seed (what the build targets)
1. **Generalize GECKO's doctor**: one skill that senses an arbitrary estate (registry/state pair, freshness, drift) → emits a coherence tile in the `estate-coherence.sh` envelope. (Subsumes recall-doctor / beads-monitor / the 8 bespoke probes.)
2. **Author `aligner` + `teeth` skills** as the cheapener + the tiered-enforcer (invariant>gate>detector), surface-not-decide.
3. **Author the `immune-relay` composition** (`sequence: doctor → aligner → teeth`, `domain: <estate>`, `surface_mode: summary`).
4. Fold the operator-port in as GECKO's commons-node skill.

## The build is HEAVY — dispatch through the harness (deliberate operator act)
Design is settled (the cheap-verify, done here). Implementation = `/simstim` or `spiral-harness.sh` (plan→build→review→audit, multi-model, evidence-gated). Per the doctrine itself: *growth is a deliberate act, collateralised on the operator's flux* — fire it when pulled, scoped to this design, not reflexively. The planning is the floor-raise's high-value half; it is done and cheap. The build is the heavy half; it waits for the pull.
