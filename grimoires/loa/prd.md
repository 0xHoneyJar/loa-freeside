## 1. Problem Statement [GROUNDED]

The Honey Jar org operates multiple Discord communities (top BGT holders, partner projects) and product worlds that need:

1. **Token-gated Discord verification** — eligibility based on on-chain holdings (BGT, NFTs) [GROUNDED: themes/sietch/src/services/eligibility.ts, packages/auth-module/src/eligibility/]
2. **Centralized AI gateway with budget enforcement** — per-community AI usage with per-model accounting, BYOK support, kill-switch [GROUNDED: packages/adapters/agent/{agent-gateway,budget-manager,ensemble-accounting,byok-proxy-handler,capability-audit}.ts]
3. **Shared infrastructure for product worlds** — multiple SvelteKit/web apps hosted on a single Freeside AWS account vs paying per-world on Railway [GROUNDED: infrastructure/terraform/world-{rektdrop,mibera,apdao,score-api}.tf, infrastructure/terraform/modules/world/]
4. **Crypto + fiat billing** — accept NowPayments, manage credit lots, x402 settlement [GROUNDED: packages/services/{nowpayments-handler,credit-lot-service,x402-settlement}.ts]
5. **Multi-protocol bot surface** — Discord (`discord.js`) + Telegram (`grammy`) + REST API [GROUNDED: themes/sietch/src/{discord,telegram,api}/]

The platform — colloquially **Freeside** (infrastructure) / **Arrakis** (npm namespace) / **sietch** (main deployment) — bundles these into one monorepo so a single AWS account, one ECS cluster, one Postgres, and one Redis serve all customers.
