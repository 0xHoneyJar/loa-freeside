## Problem

`main`'s merge gate is a **broken cut vertex** (betweenness ≈ 1.0, topology-certain): every authored→merged path runs through it and it currently *severs* the value graph. The estate looks like ~5 problems but is **1 problem with 4 shadows** — 30 rotting PRs, lying sensors, stranded extractions, no BB-merge authority all flow from the frozen door. Two diffuse meta-roots run through every cluster: **declaration ≠ ground-truth** and the **consumption-gradient slip**. Symptom-fixing recreates them. The cure is an immune system that makes declarations structurally true and the verified path structurally cheapest — and proves it can't regress.
