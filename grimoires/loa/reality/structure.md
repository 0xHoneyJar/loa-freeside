## Notable Structural Observations

- **Hexagonal architecture is intact**: `packages/core/ports/` (interfaces) ↔ `packages/adapters/*` (implementations). Textbook ports-and-adapters with 13+ port types.
- **Dual-bus migration in flight**: `apps/worker` has both `main.ts`/`main-nats.ts` and `health.ts`/`health-nats.ts` — RabbitMQ → NATS migration is staged, not fully cut over. `apps/gateway` (Rust) writes to NATS only.
- **Two CLIs**: `packages/cli` (publishes bin `gaib`, name `@arrakis/cli`, 123 files) AND `packages/gaib-cli` (smaller, has tests/) — likely staged refactor or duplication. **HYGIENE FLAG**.
- **In-tree adapter copies in sietch**: `themes/sietch/src/packages/` contains its own `core`, `security`, `wizard`, `synthesis`, `adapters`, `verification` — suggests historical pre-monorepo state or intentional embedding for deploy isolation. **HYGIENE FLAG** for review.
- **Namespace mismatch**: Repo is `loa-freeside`, code namespace is `@arrakis/*`. `apps/gateway` Cargo description references `arrakis`. Pre-rebrand or co-existence pattern.
- **Multiple PRD/SDD generations**: grimoires/loa contains `prd.md` (cycle-048 World Hosting), `gaib-prd.md`, `prd-docs-overhaul.md`, `sdd.md`, `sdd-hounfour-phase4.md`, `sdd-docs-overhaul.md` — historical layered planning artifacts.
- **External critical dep**: `@0xhoneyjar/loa-hounfour` pinned to git SHA, installed via root `postinstall` → `scripts/rebuild-hounfour-dist.sh`.
- **Migration depth**: themes/sietch has 30+ Drizzle migrations (latest: `0018_admin_audit_log.sql`, `030_credit_ledger.js`) — indicates active schema evolution.
