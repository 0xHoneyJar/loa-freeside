Solid state-colored pill — uppercase micro-label. Text color is chosen per state for contrast on its fill.

```jsx
<StatusPill state="positive">Open</StatusPill>
<StatusPill state="caution">Service</StatusPill>
```

States: `positive` (foliage), `info` (teal), `caution` (hazard — dark text, it is a light gold), `critical`, `neutral`. Use the solid pill for a primary status signal; use `StatusBadge` for the quieter tinted form.
