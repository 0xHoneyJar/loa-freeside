Card surface. Square, hairline-bordered, mineral.

```jsx
<Card variant="base"><h4>Villa Straylight</h4></Card>
<Card variant="deep">…authority content…</Card>
<Card variant="sky">…environmental content…</Card>
```

Variants: `base` (raised mineral — the default), `deep` (Deep Space authority card; set `data-register="deep-space"` on or above it), `sky` (environmental/hospitality — the one place `--fs-radius-md` is permitted, Cannes Sky hairline). Elevation is tint + hairline first, soft shadow second.
