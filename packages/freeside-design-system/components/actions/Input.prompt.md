Freeside text input. Square by default; the `mono` variant is the credit/access treatment — tracked tabular figures on a sunk surface, not a second typeface.

```jsx
<Input variant="field" placeholder="Guest name" />
<Input variant="mono" value="TA·4417·••••·2209" />
<Input variant="pill" placeholder="Ask the concierge…" />
```

Variants: `field` (default UI field, accent-1 focus ring), `mono` (credit & access — tracked tabular figures on a sunk surface, systems-pair focus), `pill` (garden context only, sky focus). Focus is a border-color change, never a glow. Accent colours come from the surface's `data-accent` pair; the variants never name a hue directly.
