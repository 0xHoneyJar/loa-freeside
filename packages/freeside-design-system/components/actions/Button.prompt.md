Freeside button — any clickable action. Square-cornered and engineered; `primary` is the everyday authority action.

```jsx
<Button variant="primary" size="lg" fullWidth>Reserve a suite</Button>
<Button variant="sky">Explore the resort</Button>
<Button variant="secondary">View rates</Button>
```

Variants: `primary` (Bermuda Sunset fill), `sky` (Cannes Sky, environmental), `secondary` (hairline border, fills on hover), `quiet` (raised fill), `ghost`. Sizes `sm|md|lg`. Disabled = opacity .5 + not-allowed. Radius `--fs-radius-sm` (2px) — the one place roundness is allowed by default.
