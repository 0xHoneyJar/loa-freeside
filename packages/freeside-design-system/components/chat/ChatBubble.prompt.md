Concierge message bubble.

```jsx
<ChatBubble role="system">Concierge · Villa Straylight</ChatBubble>
<ChatBubble role="guest">What's on the Promenade tonight?</ChatBubble>
<ChatBubble role="concierge">The lounge opens at 20:00. Shall I reserve a table?</ChatBubble>
```

Roles: `guest` (Bermuda Sunset fill, right-aligned), `concierge` (raised + hairline, left-aligned), `system` (centered italic micro-label). Max width 85%; the tail corner is squared to 2px.
