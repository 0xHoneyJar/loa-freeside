Mono message box for credit/access payloads — signable or copyable text on a sunk surface.

```jsx
<MessageBox>{`ACCT  TA·4417·2209
BAL   ₮ 128,400.00`}</MessageBox>
```

Body face at label size with added tracking and tabular figures, on a sunk surface; preserves whitespace and breaks long words. There is no mono face in this system — the machine-read quality comes from tracking, tabular numerals and the surface, not from a second typeface. Use for anything machine-read: payloads, signatures, terminal output, curl snippets.
