Doctrine 02 · Review

Roster, five contexts

Full width, because the record is a table and a cramped table reviews badly. Watch three things: the count, which describes the visible set rather than the true total; the skeleton, which is sized from the same set; and the export control, which appears with a grant and adds neither a row nor a column.

Capability is not disclosure

A grant changes what may be done. Frames three and four are identical rows and columns, one export control apart.

Metadata is a channel

Counts, skeleton rows, row identifiers and pagination figures are exports of the true total in disguise unless they are built from the visible set.

Absence is silent

A control the viewer may not use is not rendered disabled. A dead button is a worse disclosure than a plain refusal.

A presentation review. Unauthorized rows and cells must be filtered server-side, before the payload reaches the client — a row omitted from the DOM is still in the response if the server sent it.
